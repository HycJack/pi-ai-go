# 身体测量数据转换工具

一个基于 PyQt5 的桌面工具，用于将个人的身高、胸围、腰围数据，根据预设的配置规则自动匹配输出对应的配置值。

## 功能

- **数据转换**：输入性别、身高、胸围、腰围，自动按规则匹配输出配置胸围和配置腰围
- **配置管理**：
  - 胸围配置：分男女设置「身高范围 + 胸围范围 → 配置胸围值」规则
  - 腰围配置：分男女设置「身高范围 + 腰围范围 → 配置腰围值」规则
- **规则编辑**：支持新增、编辑、删除配置规则，按顺序优先匹配

## 截图

| 数据转换 | 配置管理 |
|---------|---------|
| 选择性别 → 输入数据 → 开始转换 | 分男女配置胸围和腰围规则 |

## 下载

已打包的 exe 文件见 `dist/` 目录，下载后可直接双击运行。

或下载 `身体测量数据转换工具.zip`，解压后运行。

## 使用方法

### Tab1 - 数据转换

1. 选择性别（男/女）
2. 输入身高、胸围、腰围数值（单位：cm）
3. 点击「开始转换」
4. 查看匹配结果

### Tab2 - 配置管理

#### 胸围配置规则
每条规则包含：性别、身高下限、身高上限、胸围下限、胸围上限、配置胸围值

#### 腰围配置规则
每条规则包含：性别、身高下限、身高上限、腰围下限、腰围上限、配置腰围值

> 匹配规则按顺序从上到下匹配，第一条满足条件的规则生效。

## 开发

### 环境要求

- Python 3.8+
- PyQt5

### 安装依赖

```bash
pip install PyQt5
```

### 运行

```bash
python main.py
```

### 打包

```bash
# 方式一：使用打包脚本（自动生成 .spec 文件并打包）
python build.py

# 清理后重新打包
python build.py clean

# 方式二：直接使用 PyInstaller
pyinstaller 身体测量数据转换工具.spec

# 打包后压缩
python zip_exe.py
```

### 配置文件

`body_config.json` 存储所有配置规则，格式如下：

```json
{
  "chest": [
    ["男", 150, 160, 80, 85, 82],
    ["女", 150, 160, 75, 80, 78]
  ],
  "waist": [
    ["男", 150, 160, 65, 70, 68],
    ["女", 150, 160, 60, 65, 63]
  ]
}
```

每条规则格式：`[性别, 身高下限, 身高上限, 围度下限, 围度上限, 配置值]`
