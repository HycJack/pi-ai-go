# Code Review and Fix

> Perform a comprehensive code review of a project, identify all issues, and then systematically fix them. Use this skill when asked to review code quality, audit a project, find bugs, or fix issues discovered during review.

## Steps

1. **Scan project structure** — Read the top-level directory listing to understand the project layout, language, and main entry points.

2. **Read core source files** — Read all `.go`, `.py`, `.js`, `.ts`, `.rs`, or other primary source files in the project. Focus on entry points, core types, interfaces, and error handling.

3. **Read provider/plugin implementations** — If the project uses a provider/plugin architecture, read all provider implementations to check for completeness and correctness.

4. **Read test files** — Read `*_test.go` or other test files to assess test coverage and identify untested code paths.

5. **Compile issue list** — Produce a categorized list of issues:
   - 🔴 **Critical** — Bugs, security vulnerabilities, encoding corruption
   - 🟡 **Medium** — Logic gaps, incomplete event handling, mismatched API fields
   - 🟢 **Minor** — Naming inconsistencies, type safety, missing tests

6. **Prioritize fixes** — Order fixes from most impactful to least impactful.

7. **Fix each issue** — For each issue in the prioritized list:
   - Read the exact current file content.
   - Apply the edit with a clear explanation of what changed and why.
   - Verify the edit did not corrupt surrounding code by re-reading the file after the change.

8. **Verify all fixes** — After all edits are applied, re-read all modified files to confirm correctness and consistency.

## Output

A final summary listing each issue fixed, the file and line, and the exact change made.
