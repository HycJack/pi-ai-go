# Research Workflow

对于需要多步研究的任务，按以下顺序:

1. **拆解问题**: 把复杂问题分解为 2-4 个子问题。
2. **依次搜索**: 对每个子问题调用 `search` 工具。
3. **汇总**: 把搜索结果合并成结构化答案。
4. **校验**: 如果数字/事实关键，再调用 `search` 二次确认。

## 输出格式

```
## 结论
<一句话核心答案>

## 关键发现
- 发现 1
- 发现 2

## 引用
- [标题](url)
```
